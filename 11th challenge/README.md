1. Start
2. Declare the arrays usage[5][7], dailyTarget[5] and the required variables.
3. Input the daily target and seven days' water consumption for all five zones.
4. Validate the target and consumption values.
5. Display the main menu.
6. Read the user's choice.
7. If the choice is 1, display the water consumption data.
8. If the choice is 2, calculate weekly total, daily average, peak usage, over-limit days, excess consumption, spike days and unique alert days.
9. Display the water audit report.
10. If the choice is 3, rank all five zones according to excess water consumption.
11. If the choice is 4, display suitable water conservation actions for each zone.
12. If the choice is invalid, display an error message.
13. Repeat the menu until the user selects option 5.
14. If the choice is 5, display the exit message.
15. Stop.
