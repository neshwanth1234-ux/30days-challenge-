ALGORITHM

Start.
Declare a one-dimensional array a[12] and required variables.
Read N. If N is less than 5 or greater than 12, ask again.
Read N readings. If any reading is less than 0 or greater than 1000, ask again.
Display all original readings.
Calculate the sum and average of the readings.
Find the minimum and maximum values.
Find the second-largest distinct value. If it does not exist, display a message.
Count the local peaks, where an element is greater than its previous and next elements.
Find the longest strictly increasing continuous run.
Read K and rotate the array right if K is positive or left if K is negative. If K is zero, do not rotate.
Display the rotated readings.
Read R, the last two digits of the registration number.
Calculate D = (R % 9) + 1.
Count the rotated readings divisible by D.
Display the divisible count.
Stop.
