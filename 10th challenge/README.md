ALGORITHM 
1. Start.
2. Display the menu.
3. Read the user’s choice.
4. If the user chooses input, read and validate temperature, humidity, and AQI for every zone and day. Ask again for invalid readings.
5. If the user chooses an analysis option, check that readings have been entered. If not, display “Enter data first.”
6. If readings are available, perform the selected task: display readings, calculate averages, identify risk days, calculate and rank Green Index scores, or show recommendations.
7. If the choice is invalid, display an error message.
8. If the user has not chosen Exit.
9. Stop.
