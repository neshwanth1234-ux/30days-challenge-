1. Start.
2. Declare a one-dimensional array a[12] and required variables.
3. Read N. If N is less than 5 or greater than 12, ask again.
4. Read N. If any reading is less than 0 or greater than 1000, ask again.
5. Display all original readings.
6. Calculate the sum and average of the readings.
7. Find the minimum and maximum values.
8. Find the second-largest distinct value. If it does not exist, display a message.
9. Count the local peaks, where an element is greater than its previous and next elements.
10. Find the longest strictly increasing continuous run.
11. Read K and rotate the array right if K is positive or left if K is negative. If K is zero, do not rotate.
12. Display the rotated readings.
13. Read R, the last two digits of the registration number.
14. Calculate D = (R % 9) + 1.
15. Count the rotated readings divisible by D.
16. Display the divisible count.
17. Stop.
