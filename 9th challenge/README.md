ALGORITHM 

1. Start.
2. Set the auditorium size to 5 rows and 8 seats per row.
3. Mark all seats as available.
4. Display the menu options.
5. Read the user’s choice.
6. If requested, display the seat arrangement.
7. Book or cancel a seat after checking its row, seat number, and status.
8. For a group, find and book the first suitable consecutive seats in one row.
9. Display the occupancy report when selected.
10. Repeat the menu until Exit is chosen. 
11. stop.
